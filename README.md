# Workflow Desk

Independent English-language landing page about practical business automation.

## Deployment to Cloudflare Pages

1. In Cloudflare Dashboard, open Workers & Pages > Create application > Pages > Connect to Git.
2. Authorize GitHub and choose `lenixeduardo/workflow-desk`.
3. Set production branch to `main`.
4. Framework preset: None. Build command: leave blank. Build output directory: `/` (repository root).
5. Deploy. Cloudflare will assign a `.pages.dev` URL.
